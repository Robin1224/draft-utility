# Phase 9 — UI Design Contract: Signature Effects Infrastructure

> Visual and interaction contract for the three reusable, motion-safe Cyber signature effects. Generated by gsd-ui-researcher, verified by gsd-ui-checker.
>
> **This phase is NOT screens.** It delivers three reusable Svelte 5 building blocks that Phase 10+ screens drop in:
> 1. The **ASCII plasma shader** canvas (mounts into the existing `CyShell` `.cy-shader` slot).
> 2. A **typed terminal-log** mechanism (rune-based utility / component) consumed by Home boot log (Phase 10) and the connect log (Phase 12).
> 3. The **shaded-ASCII `DRAFT` wordmark** with line-by-line reveal (consumed by Home hero, Phase 10).
>
> **Authoritative source — port VERBATIM:** `design_handoff_pickban_cyber/prototype/variants/cyber.jsx` (behavior) and `cyber.css` (values). React is the prototyping medium only — reimplement as Svelte 5. Every glyph string, numeric constant, color-ramp formula, and CSS keyframe below is transcribed from those files. Do NOT approximate — these values are load-bearing for fidelity (PROJECT decisions / REQUIREMENTS milestone banner).
>
> **Requirements covered:** FX-01, FX-02, FX-03, FX-04.
>
> **Depends on Phase 8 (shipped):** `.cy-app` token scope, JetBrains Mono, the empty `.cy-shader` mount point in `src/lib/components/chrome/CyShell.svelte`, the `cy-blink` keyframe, and the reduced-motion pattern already in `src/app.css`. Do NOT contradict Phase 8 decisions (plain CSS, no Tailwind, hybrid CSS org, zero border-radius, reduced-motion honored everywhere).

## ⚠️ FLAG — One Open Design Question (wordmark text)

**Question:** The header brand is `[ DRAFT_EM ]` (Phase 8 D-06, the registered domain). The hero shaded-ASCII block-art (`CY_LOGO_LINES`) spells **`DRAFT`** (5 glyphs). Should the hero block-art be regenerated to read `DRAFT_EM`, or kept as `DRAFT`?

**Recommended default (this spec adopts it):** **Keep the existing `DRAFT` block-art verbatim.**
- Regenerating shaded ANSI block-art (`░▒▓█` style) for a longer string (`DRAFT_EM`) is non-trivial hand-work and risks fidelity drift.
- The header already carries the full `[ DRAFT_EM ]` brand on every screen, so brand identity is covered.
- The hero wordmark reads as the product short-name `DRAFT`; this is an accepted, intentional split (long-form brand in chrome, short-form mark in hero).

**If the human overrides** (wants `DRAFT_EM` block-art): that is new ASCII-art authoring work, not a transcription, and should be scoped as its own task in planning. This spec does NOT block on the answer — it proceeds with the recommended default and the planner/executor use `CY_LOGO_LINES` as-is unless overridden.

## Effect 1 — ASCII Plasma Shader (FX-01, FX-02)

A `<canvas>` rendering a grid of monospace glyphs whose density is driven by an animated, domain-warped plasma field, colored on a violet→lime brightness ramp. Mounts into the **existing** `.cy-shader` slot in `CyShell.svelte` (absolute, behind content, `z-index: 0`, `pointer-events: none`). Source: `cyber.jsx` §`CYShader` (lines ~65–151).

### Component contract

| Aspect | Contract |
|--------|----------|
| Form | A Svelte 5 component (e.g. `CyShader.svelte`) rendering a single `<canvas>` with class `cy-shader` (+ `cy-shader-hot` when `hot`), `aria-hidden="true"` |
| Props | `intensity` (number, default `1`), `hot` (boolean, default `false`) — match the React signature exactly |
| Mount target | Replaces the empty `<div class="cy-shader">` in `CyShell.svelte`. The component renders the `<canvas>` itself carrying the `cy-shader` class; the existing CSS positioning rules apply unchanged |
| Drawing API | 2D canvas context (`getContext("2d")`), glyph fill via `ctx.fillText` |

### Exact constants (transcribe verbatim from `cyber.jsx`)

| Constant | Ambient (`hot=false`) | Hot (`hot=true`) |
|----------|----------------------|------------------|
| Density ramp `CY_RAMP` | `" .:-=+*o#%@"` (low→high; leading space is index 0) | same |
| Cell size (glyph cell, CSS px) | `14` | `16` |
| Frame cap (fps) | `30` | `60` |
| Speed multiplier `sp` | `1` | `1.25` |
| Brightness shaping | `v = v * v * v` (sparse ridges) | `v = Math.pow(v, 1.5)` (denser) |
| Per-level alpha `a` | `(0.05 + v*v*0.5) * intensity` | `(0.26 + v*v*0.95) * intensity` |
| CSS opacity (on canvas element) | `.cy-shader` → `0.9` | `.cy-shader-hot` → `1` |

### Color ramp (per-density-level palette — precompute once, verbatim)

For each level `i` of `CY_RAMP` (`levels = CY_RAMP.length` = 11), with `v = i / (levels - 1)`:
```
r = round(140 + (179 - 140)*v + (v > 0.6 ? (v - 0.6)*120 : 0))   // clamp max 205
g = round(40 + (255 - 40)*v)                                      // clamp max 255
b = round(200 - 160*v)                                            // clamp min 40
a = (hot ? 0.26 + v*v*0.95 : 0.05 + v*v*0.5) * intensity          // a.toFixed(3)
color = `rgba(min(r,205), min(g,255), max(b,40), a)`
```
Low density → dim violet; mid → violet→lime transition; high → bright lime. **Color is procedural, not from tokens** — these RGB formulas ARE the contract (they encode the violet→lime ramp). Do not substitute `--cy-lime` / `--cy-violet`.

### Plasma field math (per cell, per frame — verbatim)

```
t  = (now - t0) * 0.001 * sp
wx = sin(gy*0.12 + t*0.9) * 2.6          // domain warp x
wy = cos(gx*0.10 - t*0.7) * 2.6          // domain warp y
dx = gx - cx; dy = gy - cy; d = sqrt(dx*dx + dy*dy)   // cx,cy = grid center
v  = sin((gx+wx)*0.11 + t*1.3)
   + sin((gy+wy)*0.10 - t*1.05)
   + sin((gx+gy)*0.07 + t*0.85)
   + 0.7 * sin(d*0.09 - t*1.6)
v  = (v + 3.7) / 7.4                      // normalize → ~0..1
clamp v to [0,1]
v  = hot ? pow(v,1.5) : v*v*v
lvl = (v * (levels-1)) | 0
if (lvl <= 0) continue                    // PERF: skip spaces — do not draw index 0
clamp lvl to levels-1
fillStyle = colors[lvl]; fillText(CY_RAMP[lvl], gx*cell, gy*cell)
```

### Canvas sizing (verbatim)

- `dpr = min(window.devicePixelRatio || 1, 2)` — **clamp DPR to 2** (perf).
- `cols = ceil(width / cell)`, `rows = ceil(height / cell)`.
- `canvas.width = floor(width * dpr)`, `canvas.height = floor(height * dpr)`; `ctx.setTransform(dpr,0,0,dpr,0,0)`.
- `ctx.font = `${cell}px "JetBrains Mono", ui-monospace, monospace``; `ctx.textBaseline = "top"`.
- Bail out of `resize()` when the rect has zero width/height.

### Motion-safety & lifecycle obligations (FX-02 — MANDATORY)

| Obligation | Behavior |
|-----------|----------|
| **Off-screen pause** | An `IntersectionObserver` (`threshold: 0.01`) on the canvas sets a `visible` flag. The rAF `frame()` keeps scheduling but **returns early without drawing** when `!visible`. The shader must **visibly pause when scrolled off-screen** (success criterion 2). |
| **Resize** | A `ResizeObserver` on the canvas re-runs `resize()`. |
| **Frame cap** | In `frame(now)`, skip drawing while `now - last < 1000 / fps`. |
| **prefers-reduced-motion** | When `(prefers-reduced-motion: reduce)` matches, the shader **does not animate at all** (success criterion 2). Recommended Svelte approach: do not start the rAF loop under reduced motion. Acceptable to render a single static frame OR render nothing — the hard rule is **zero ongoing animation**. Mirror the prototype's reduced-motion intent (the prototype disables the typed-log loop; apply the same disable to the shader loop). |
| **Cleanup (Svelte 5)** | The `$effect` that owns the canvas MUST return a teardown that runs `cancelAnimationFrame(raf)`, `ro.disconnect()`, and `io.disconnect()`. React's `useEffect` cleanup maps 1:1 to the `$effect` return function. Re-create the loop when `intensity`/`hot` change (these are the React dep array). Guard all `window`/`matchMedia` access for SSR (`typeof window !== "undefined"`). |

### CSS (already present in `src/app.css` from Phase 8 — do NOT duplicate)

`.cy-shader` (absolute, inset 0, z-index 0, pointer-events none, 100% w/h, `opacity: 0.9`) and `.cy-shader-hot { opacity: 1; }` already exist verbatim. Phase 9 only fills the canvas; the positioning CSS is untouched.

## Effect 2 — Typed Terminal Log (FX-03)

A reusable mechanism that prints an array of lines character-by-character, then signals `done`. Source: `cyber.jsx` §`useTypedLog` (lines ~35–57).

### Component / utility contract

| Aspect | Contract |
|--------|----------|
| Form | A **rune-based reusable utility** (`.svelte.js` module exposing a `createTypedLog(lines, opts)` factory) OR a thin component wrapper — planner's call. It must be reusable across screens (Home boot log Phase 10, connect log Phase 12), matching the React hook's reusability. |
| Input | `lines: string[]`, options `{ speed = 9, lineGap = 60 }` (ms). |
| Output (reactive) | `{ text: string, done: boolean }` — `text` is the visible prefix `full.slice(0, n)`; `done` is `n >= full.length`. Consumers read these reactively. |
| Internal buffer | `full = lines.join("\n")`. |

### Exact timing (transcribe verbatim)

| Param | Default | Notes |
|-------|---------|-------|
| `speed` | `9` ms/char | Per-character delay (Home boot log uses default). |
| `lineGap` | `60` ms | Delay applied after a newline (`full[i-1] === "\n"`) — pause between lines. |
| Initial delay | `300` ms | First `setTimeout(step, 300)` before typing starts. |
| Connect-log override (Phase 12) | `speed: 7, lineGap: 120` | The reference calls `useTypedLog(CY_CONNECT_LINES, { speed: 7, lineGap: 120 })` — record so Phase 12 reproduces it. Not built in Phase 9 unless the utility is generic (it is). |

### Stepping behavior (verbatim)

```
i starts at 0; each step: i += 1; n = i;
if i >= full.length → stop (done)
nextDelay = (full[i-1] === "\n") ? lineGap : speed
schedule next step after nextDelay
```

### Motion-safety & lifecycle obligations (FX-03 — MANDATORY)

| Obligation | Behavior |
|-----------|----------|
| **prefers-reduced-motion** | If `(prefers-reduced-motion: reduce)` matches, **initialize `n` to `full.length`** so `text` is the full buffer and `done` is `true` immediately — **no typing, jump straight to full text** (success criterion 3). Mirror the React `reduced ? full.length : 0` branch and the early `return` that skips the timer. |
| **Cleanup (Svelte 5)** | The driving `$effect` MUST `clearTimeout` the pending timer in its teardown (React returns `() => clearTimeout(timer)`). Restart when inputs change (deps: `full`, `reduced`, `speed`, `lineGap`). |
| **SSR guard** | Guard `window`/`window.matchMedia` (`typeof window !== "undefined" && window.matchMedia`). |
| **Trailing cursor (consumer concern)** | Consumers may render a blinking `▮` while `!done` (e.g. connect log) using the existing `cy-blink` keyframe — that keyframe already lives in `src/app.css` and is reduced-motion-suppressed. The typed-log utility itself does not own a cursor. |

### Reveal animation (port CSS verbatim from `cyber.css` lines 131–178)

| Aspect | Contract |
|--------|----------|
| Base visibility | `.cy-logo` is **always visible** (base state). The reveal animates a **slide + glow flash only, never opacity** — so the logo can NEVER get stuck hidden. This is a deliberate fidelity guardrail; do not animate opacity in. |
| Per-line stagger | `.cy-logo-wrap.is-rendered .cy-logo-line` runs `cy-logo-in 0.5s cubic-bezier(0.2,0.7,0.3,1) backwards`, with `:nth-child(1..9)` delays `0.02s, 0.08s, 0.14s, 0.20s, 0.26s, 0.32s, 0.38s, 0.44s, 0.50s`. |
| `@keyframes cy-logo-in` | `from { transform: translateX(-12px); filter: brightness(2.6); }` `55% { filter: brightness(1.5); }` `to { transform: translateX(0); filter: brightness(1); }` |
| Logo color/glow | `.cy-logo`: `font-size: 13px; line-height: 1.05; font-weight: 700; white-space: pre; color: var(--cy-lime); text-shadow: 1px 0 var(--cy-violet), -1px 0 rgba(40,200,255,0.55), 0 0 12px rgba(179,255,61,0.4);` (chromatic-aberration ASCII). |
| Glitch ghost | `.cy-logo-glitch` (violet, `opacity: 0`, `mix-blend-mode: screen`) runs `cy-glitch 6.5s steps(1) infinite` with `animation-delay: 1.2s` once rendered. Keyframes per `cyber.css` lines 168–174 (verbatim). |

### Motion-safety obligations (FX-04 — MANDATORY)

Port the reduced-motion block verbatim (`cyber.css` lines 175–178):
```css
@media (prefers-reduced-motion: reduce) {
  .cy-logo-wrap.is-rendered .cy-logo-line { animation: none; }
  .cy-logo-glitch { animation: none !important; }
}
```
Because the base `.cy-logo` is always visible, suppressing the reveal/glitch under reduced motion leaves the **fully-formed wordmark statically visible** — the line-by-line reveal simply does not play. Success criterion 4 (the wordmark renders with its line-by-line reveal) is met for motion-enabled users; reduced-motion users see the final static wordmark.
