# Phase 11 — UI Design Contract: Terminal Modals

> Visual and interaction contract for MOD-01 (Draft Settings modal) and MOD-02 (Host Console modal). Generated by gsd-ui-researcher, verified by gsd-ui-checker.
>
> **Authoritative sources:** `design_handoff_pickban_cyber/prototype/variants/cyber.css` (lines 520–599, port verbatim) and `cyber.jsx` (`CYScriptEditor` ~726, `CYSettings` ~785, `CYHostControls` ~833). Locked decisions D-01..D-11 from `11-CONTEXT.md` are authoritative. This spec APPENDS to the Phase 8–10 design system — it does not re-decide tokens, fonts, or radius.

## Component Contracts

### 1. `CyModal.svelte` (new, `src/lib/components/atoms/`)

Shared wrapper on native `<dialog>` (D-07). Anatomy top-to-bottom:

1. **Titlebar** `.cy-modal-bar`: three bordered 9px dots (`.cy-dot-r` red, `.cy-dot-a` amber, `.cy-dot-g` lime, in that order, aria-hidden), `.cy-modal-title` path string, `.cy-modal-x` button (`esc ✕`) pushed right via `margin-left: auto`.
2. **Body** `.cy-modal-body`: `padding: 22px 24px`, column flex `gap: 18px`, `overflow-y: auto`, `overscroll-behavior: contain`. First child is `.cy-modal-head` (`> HEADING` h3 + `// comment` p).
3. **Footer** `.cy-modal-foot` (snippet, optional): `padding: 14px 24px`, top border, `.cy-grow` spacer for alignment.

**Dialog CSS adaptations (required deviations from verbatim, per RESEARCH):**
- `dialog.cy-modal { padding: 0; color: inherit; width: 100%; max-width: 560px; max-height: 86%; background/border/box-shadow verbatim (cyber.css 528–533); }` — neutralizes UA `padding: 1em` / `color: CanvasText` / UA max-sizing.
- `display: flex; flex-direction: column;` lives on `dialog.cy-modal[open]` ONLY (unguarded flex makes the closed dialog visible — UA `dialog:not([open]){display:none}` loses to author origin).
- Scrim = `dialog.cy-modal::backdrop` carrying `.cy-modal-scrim` literals (cyber.css 521–526); grid-centering/32px padding are replaced by the dialog's native top-layer `margin: auto`.

**Dismissal (D-08):** esc (native `cancel` event), scrim click (`click` where `e.target === dialogEl` — reliable because `padding: 0`), and `✕` all route through one `requestDismiss()` with an `onAttemptClose` veto callback. `close` event is the single source of truth for "closed" (resets bound `open`; cleanup lives here, never on `cancel` — Chromium may force-close on second Escape).

**Focus:** browser-owned — `showModal()` traps focus, inerts background, returns focus to the launcher on `close()`. Dialog stays mounted permanently (never `{#if open}<dialog>`). `aria-label={title}` on the dialog.

### 2. Slim launcher bar (`LobbyHostBar.svelte` rework, D-01..03)

- Keeps the shipped Phase 10 `.cy-host-panel` shell with the amber `[HOST_CONSOLE]` head label (discretion resolved: reuse, zero new classes).
- Row of existing `.cy-btn cy-btn-sm` buttons: `COPY_LINK`, `CONFIG()`, `HOST_CONSOLE()`, `▶ START_DRAFT()` (`.cy-btn-primary`, `disabled={startDisabled}`) + captain hint when gated.
- Inline move/kick/settings UI removed from the bar. `CANCEL_ROOM` removed from the bar (Console footer only, D-03).
- Both `▶ START_DRAFT()` instances share the single existing `startDisabled` `$derived` (D-02).
- Entire surface (launchers + both modals) inside the existing `{#if isHost}` guard.

### 3. Draft Settings modal body (MOD-01)

- **Stepper** `.cy-field` > `turn_timer` label + `.cy-stepper`: `−` button (aria-label `decrease`, glyph U+2212), `.cy-stepper-val` `{n}` + `<span>sec</span>`, `+` button (aria-label `increase`). Clamp `Math.max(10, t−5)` / `Math.min(120, t+5)` — 10–120 step 5; buttons visually unchanged at bounds (value simply stops). Hold-to-repeat: NOT required (discretion: skip).
- **Script editor** `.cy-field` (label `pick / ban order — drag ⠿ to reorder`) > `.cy-script` list of `.cy-script-row`s + `+ ADD_TURN` (`.cy-btn cy-btn-sm cy-script-add`). Data shape frozen: `{ id, team: 'A'|'B', action: 'pick'|'ban' }`, new rows `{ team:'A', action:'ban' }` with `nanoid(8)` id.
- **Draft-copy semantics (D-04):** open snapshots `{ script, timerSeconds }` (`structuredClone($state.snapshot(...))`); edits hit the copy only; `SAVE_CONFIG()` commits to page state; any dismissal discards. Dirty = ordered `[team, action]` tuples + timer differ from the open snapshot (id churn is not dirty).
- **Dirty dismiss (D-05/06):** dirty + dismiss attempt → veto + footer swaps to `// discard unsaved config?` `[DISCARD]`/`[KEEP_EDITING]`; second esc (or `[DISCARD]`) closes and discards; `[KEEP_EDITING]` restores the normal footer. Clean modal closes silently.

### 4. Script row (`ScriptTurnRow.svelte` rework, D-11)

- Grid: `18px 22px 1fr 1fr auto auto auto` — **justified deviation** from verbatim `18px 22px 1fr 1fr auto` (cyber.css 567) to seat `[↑]` `[↓]` before `rm` as explicit columns (consistent cross-row alignment).
- Cells: `⠿` grip (aria-hidden, `cursor: grab`, drag handle — desktop enhancement) · zero-padded index (`--cy-text-3`, right-aligned) · team select (`.team-a` lime / `.team-b` violet) · action select (`.is-ban` red / `.is-pick` lime) · `↑` · `↓` · `rm`.
- `↑`/`↓` styled identically to `.cy-script-rm` (transparent, 1px `--cy-line` border, `--cy-text-3`, 11px, `padding: 4px 8px`; hover → `--cy-line-2` border, `--cy-text-2` — neutral, NOT red; red hover stays exclusive to `rm`). Disabled at ends (`i === 0` / `i === length−1`) via existing disabled treatment (`opacity`/`cursor: default`), preserving column alignment.
- `rm` accessible name: `remove turn {N}` (aria-label).
- Drag state `.is-drag`: dashed amber border, `opacity: 0.6` (verbatim). One data path for reorder: drag, buttons, and keyboard all splice the same copy.

### 5. Host Console modal body (MOD-02)

- `move_player` section: `.cy-hc-row` = player select (`.cy-input`, flex 1) + target select (`→ A`/`→ B`, `flex: 0 0 90px`) + `EXEC` (`.cy-btn cy-btn-sm`). Calls existing `onMove(userId, toTeam)` — signature frozen.
- `kick` section: `.cy-kick-list` of `.cy-kick-item` (name · `team_X · cap` meta · `.cy-grow` · `kick()` `.cy-kick-btn`). Calls existing `onKick(payload)` via existing `kickPayload()` — frozen. Accessible name: `kick {displayName}` (default).
- Captain hint `.cy-hc-hint` (amber dashed border, `!` badge via `::before`) rendered only when a captain is missing (existing `showCaptainHint` derive).
- Footer: `CANCEL_ROOM` (`.cy-btn-danger`, left) · `.cy-grow` · `▶ START_DRAFT()` (`.cy-btn-primary`, `disabled={startDisabled}`).
- No dirty state — always dismisses freely (D-05).

## Responsive Contract

| Range | Behavior |
|-------|----------|
| > 640px | Centered `.cy-modal` box: `max-width: 560px; max-height: 86%`; body scrolls between fixed bar and footer |
| ≤ 640px | Full-screen takeover (D-10): `max-width: none; max-height: none; width: 100vw; height: 100dvh; margin: 0` — titlebar pinned top, footer pinned bottom, body scrolls (`dvh` for mobile URL-bar collapse) |

**Breakpoint: `@media (max-width: 640px)`** — discretion resolved per RESEARCH A3 (560px modal + 2×32px prototype gutters = 624px). CSS-only, lives in app.css (first width media query there — the prototype has none; Phase 10's 1100px chat breakpoint is a JS `matchMedia` structural swap and is NOT the convention for this case). Script-row selects are `1fr` and shrink; verify the 7-column row fits at 320px width.

## Accessibility Contract

- Native `<dialog>` + `showModal()`: implicit `role="dialog"`, focus trap, inert background, esc, focus-return — browser-owned, no hand-rolled trap.
- `aria-label` on dialog = title string; stepper buttons `decrease`/`increase` (prototype-verbatim); `rm` → `remove turn {N}`; `↑`/`↓` → `move turn {N} up/down`; grip and titlebar dots `aria-hidden`.
- `[↑]`/`[↓]` buttons are the keyboard/touch reorder path (D-11); HTML5 grip drag is enhancement only.
- Disabled `▶ START_DRAFT()` uses the `disabled` attribute (both instances); the amber hint is the visible explanation.
- All text via Svelte interpolation (auto-escaped); no `{@html}`.
