CyModal.svelte props (JSDoc-typed, `/** @import { Snippet } from 'svelte' */`):

```javascript
/**
 * @type {{
 *   open?: boolean,                  // $bindable(false) — parent drives showModal()/close()
 *   title: string,                   // titlebar path string + dialog aria-label
 *   onAttemptClose?: () => boolean,  // return false to veto dismissal (esc/scrim/✕)
 *   children: Snippet,               // rendered inside .cy-modal-body
 *   footer?: Snippet                 // rendered inside .cy-modal-foot when provided
 * }}
 */
```

Behavioral contract:
- Dialog stays mounted permanently; `$effect` syncs `open` ↔ `showModal()`/`close()`.
- `cancel` event (esc): call `onAttemptClose`; `e.preventDefault()` when it returns false.
- `click` where `e.target === dialogEl` (scrim) and the `esc ✕` button: route through one `requestDismiss()` that honors the same veto.
- `close` event: sets `open = false` — the single source of truth for "closed" (callers hang cleanup on `open` flipping false, never on `cancel`).
</interfaces>
