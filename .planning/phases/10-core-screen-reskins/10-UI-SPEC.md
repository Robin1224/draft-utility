# Phase 10 — UI Design Contract

> Visual and interaction contract for the Core Screen Reskins (Home, Login, Lobby, Drafting, Pause, Review). Generated by gsd-ui-researcher, verified by gsd-ui-checker.
>
> **This phase has NO standalone design system to invent.** The Cyber design system was fully established in Phase 8 (tokens, JetBrains Mono, `.cy-app` scope, zero-radius, chrome) and Phase 9 (shader, typed log, wordmark). All values below are PORTED VERBATIM from `design_handoff_pickban_cyber/prototype/variants/cyber.css` and reproduced in `src/app.css` — they are not new decisions. The contract here is to apply them faithfully without drift. Do not invent new tokens, sizes, or colors.

## Spacing Scale

The Cyber system is monospace and dense; it does NOT use a strict 8-point scale. Spacing values are ported verbatim from `cyber.css` and are load-bearing for fidelity (DS-02 / Phase 8 D-03). The executor MUST reuse the per-screen padding/gap values already in `cyber.css`, not normalize them to an arbitrary scale.

| Token | Value | Usage |
|-------|-------|-------|
| 2xs | 2px | Pill padding (`cy-tag`, `cy-review-ban`), tab vertical padding |
| xs | 4px | Brand/header gaps, card-num gap, slot-num spacing |
| sm | 6px | Slot-list gaps, champ-grid gaps, draft-col section gaps |
| md | 8px | Button gaps, action stacks, meta gaps, chat gaps |
| lg | 12px | Card padding rows, draft-grid gaps, slot padding |
| xl | 16px | Card/team/lobby-grid gaps, team-head margin |
| 2xl | 20px | Card/team/host-panel/pause-card inner padding |
| 3xl | 24px | Review section gaps, banner padding |
| 4xl | 32px | Page padding (home/login/review), pause/login card padding |
| 5xl | 40px | Pause/loading screen outer padding |

**Exceptions / non-multiple-of-4 values that are INTENTIONAL and must be preserved verbatim:**
- `cy-home` padding `40px 32px 24px`; `cy-frame` padding `26px 30px 30px`
- `cy-input-wrap` / `cy-input-bare` padding `9px 0`, `0 10px`
- `cy-btn` padding `10px 16px`; `cy-card-btn` padding `11px`; `cy-btn-discord` / `cy-submit` padding `14px`
- `cy-slot` padding `10px 12px`; `cy-pickslot` `min-height: 52px`; `cy-pickslot-art` `40px`
- `cy-boot` `min-height: 9.3em`; `cy-loading-log` `min-height: 8.4em` (layout reservation for typed text — do not change)

Rationale: these come from `cyber.css` and are part of the verbatim-fidelity contract (DS-02). The checker's spacing dimension should treat the ported `cyber.css` values as the canonical scale for this phase, NOT flag them as off-grid.

## Typography

All text is JetBrains Mono. Weight range is 400 (default) / 700 (logos, brand, headings). 500/600 are loaded and available but the ported screens predominantly use 400 + 700. Sizes are ported verbatim from `cyber.css` — these specific px values are the contract.

| Role | Size | Weight | Line Height | Notes / where |
|------|------|--------|-------------|---------------|
| Display (clock) | 56px (draft) / 64px (pause) | 400 | 1 | `cy-turn-clock-num`, `cy-pause-timer-num`; `font-variant-numeric: tabular-nums` |
| Heading (screen) | 22–28px | 400/700 | ~1.2 | `cy-review-head h2` 28px, `cy-banner h2` 22px, `cy-login-card h2` 24px, `cy-turn-team` 24px, `cy-pause-card h2` 24px |
| Subhead / card title | 16–19px | 400 | ~1.2 | `cy-card-title` 19px, `cy-team-head` 16px, `cy-hero-tagline` 16px |
| Body | 13px | 400 | 1.5 | `cy-card-desc`, `cy-slot`, `cy-input`, `cy-banner p`, `cy-login-card p`, default screen copy |
| Label / meta | 11–12px | 400 | 1.5–1.55 | `cy-boot` 12px, headers 12px, eyebrows/labels 11px, `cy-champ-name` 11px, `cy-tag` 10px |
| Micro | 9–10px | 400 | 1 | `cy-champ-role` 9px, `cy-banner-stats span` 10px, smallest pills |

Logo/wordmark: `cy-logo` 13px / weight 700 / line-height 1.05 (already shipped in Phase 9 — do not alter).

**Heading line-height contract:** 1.2 for multi-word headings. **Body line-height contract:** 1.5 (`cy-card-desc`, `cy-gate-card p`). Clock/numeric displays use line-height 1.

## Color

The 60/30/10 framing maps onto the Cyber palette as follows. All hex values are the verbatim tokens already in `src/app.css` under `.cy-app` (DS-02). Do not introduce new colors.

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `--cy-bg` #050409 (+ `--cy-bg-2` #0a0814, `--cy-bg-3` #110d22) | Page background, scrolling body, inputs; radial violet gradient backdrop on `.cy-app` |
| Secondary (30%) | `--cy-bg-2` #0a0814 surfaces with `--cy-line` #2a1f4a / `--cy-line-2` #4a3580 1px borders; text `--cy-text` #e8e0ff, `--cy-text-2` #9080c0, `--cy-text-3` #5a4880 | Cards, team columns, panels, banner, chat, modals; the structural chrome |
| Accent (10%) | `--cy-lime` #b3ff3d (glow `0 0 12px #b3ff3d80`) and `--cy-violet` #c44bff (glow `0 0 12px #c44bff80`) | See reserved-for list below |
| Destructive | `--cy-red` #ff2255 | See destructive list below |
| Warning | `--cy-amber` #ffaa00 | Captain tag (`cy-tag-cap`), host-panel head, active turn pip, active empty pickslot — NOT a general accent |

**Lime (`--cy-lime`) reserved for:**
- Team A accent (`cy-team-lime`, `cy-draft-col-lime`, `cy-turn-lime`) and Team A pick column
- Primary CTA fill/glow: `CREATE_DRAFT()` / `▶ START_DRAFT()` / `$ NEW_DRAFT()` (`cy-btn-primary`, `cy-submit`, `cy-card-btn` on hover)
- Brand wordmark, active phase in tracker, screen headings (`h2`), input focus outline, success/OK log lines
- The DRAFT ASCII wordmark and the blinking block cursor

**Violet (`--cy-violet`) reserved for:**
- Team B accent (`cy-team-violet`, `cy-draft-col-violet`, `cy-turn-violet`) and Team B pick column
- Eyebrows / section markers (`cy-login-eyebrow`, `cy-banner-eyebrow`, `cy-review-eyebrow`, `cy-pause-eyebrow`)
- Big stat numbers (`cy-banner-stats b`), room-code meta value, ASCII frame border + card corner ticks, pause card border/timer
- Scanline tint, shader brightness ramp top end

**Red (`--cy-red`) reserved for:**
- Ban column treatment: ban submit button (`cy-submit-ban`), banned champion X overlay, struck-through ban names (`cy-pickslot.is-ban` + `cy-review-ban` line-through)
- Countdown urgency state in final 5s (D-04: color shift; pulse only when motion allowed)
- Destructive controls (`cy-btn-danger` hover, kick button) and error log lines (`[ERR]`)

Never use accent colors as plain interactive defaults. Default interactive state is `--cy-text` on transparent with `--cy-line-2` border; lime appears only on hover/primary.

## Copywriting Contract

All copy follows the terminal/command aesthetic: UPPERCASE function-call labels with `()`, `$`-prefixed command eyebrows, `//` comment annotations, `[ OK ]/[ERR]/[INF]` log tags. Verbatim strings below are ported from `cyber.jsx` except the Home boot log, which is overridden by CONTEXT D-03.

| Element | Copy |
|---------|------|
| Primary CTA — Home create | `CREATE_DRAFT()` (card title `> SPAWN_ROOM`, action `▸ EXECUTE`) |
| Secondary — Home join | `> JOIN_ROOM` card, input placeholder `K7-MIRA`, action `▸ CONNECT` |
| Home tagline | `> REAL-TIME PICK/BAN PROTOCOL` (`>` lime, `/` violet) |
| Home boot log (VERBATIM, D-03) | `$ draft --connect` / `[ OK ] handshake with draftnet ...... ok` / `[ OK ] syncing champion catalog ..... 28` / `[ OK ] team channels A/B ............ open` / `[ OK ] turn clock .................... 30s` / `> ready_` — final line ends with blinking cursor; updates `CY_BOOT_LINES` in `cyTypedLog.svelte.js` + its spec assertion |
| Login eyebrow / heading | `$ ./auth --provider=discord` / `USER_AUTH_REQUIRED` |
| Login body | `// signed-in users can host or captain. guests = spectate only.` |
| Login Discord CTA | `CONTINUE_DISCORD()` |
| Login guest CTA | `SPECTATE_AS_GUEST()` (divider `--- // ---`) |
| Login footer | `// chat_filter: ENABLED · slur_block: ENABLED` |
| Lobby join-team CTA | `JOIN_TEAM_A()` / `JOIN_TEAM_B()` (`cy-btn-{accent}-block`) |
| Lobby host bar | `EXEC` · `CONFIG` · `CANCEL` (danger) · `▶ START_DRAFT()` (primary) — modal targets are Phase 11, labels live here |
| Empty slot (lobby) | `<EMPTY>` label inside dashed `cy-slot-empty` (roadmap calls it `[ open slot ]` — render the dashed empty slot with `<EMPTY>` per cyber.jsx; either is acceptable, pick one and be consistent) |
| Captain marker | `cy-tag cy-tag-cap` amber pill (e.g. `CAP`) |
| Drafting lock-in CTA | `$ {action}({champName}) [LOCK_IN]` where action = `PICK` (lime submit) or `BAN` (red submit) |
| Drafting empty pickslot | active turn slot shows action label uppercase (e.g. `PICKING…` / `BANNING…`) on `cy-pickslot-empty.is-active` |
| Pause eyebrow / heading | `// CONNECTION_LOST` / `$ DRAFT.HOLD()` |
| Pause event log | `[ERR] {team}.captain.socket: closed` / `[INF] grace_period: {n}s` / `[INF] awaiting reconnect…` (bind real values to frozen snapshot) |
| Pause footer | `> if no reconnect, captaincy promotes to next {team} member` |
| Review actions | `$ COPY_LINK()` (default) / `$ NEW_DRAFT()` (primary) |
| Review bans label | `BANS:` followed by struck `cy-review-ban` pills |
| Empty state (no data, generic) | Terminal style: `// no_data` or `[ .. ] awaiting …` rather than prose; prefer the screen's existing dashed-empty pattern |
| Error state (load failure) | Terminal style: `[ERR] {what failed} — {retry path}`, e.g. `[ERR] snapshot hydrate failed — retry()` (discretionary per CONTEXT; keep `[ERR]` tag + retry verb) |
| Destructive confirmation | `CANCEL` / `CANCEL_ROOM` triggers a confirm — host-bar Cancel and kick are destructive; confirmation flow itself (modal) is Phase 11/12. In Phase 10, destructive buttons use `cy-btn-danger` (red on hover) and must not fire without confirmation; do not change existing confirm behavior |

**Destructive actions in this phase:** none are newly wired. Cancel-room and kick controls are restyled only (their interactive modals are Phase 11/12). Apply `cy-btn-danger` styling; preserve existing confirmation behavior unchanged (presentational phase, D-01).

## Interaction & State Contract (phase-specific)

| Interaction | Contract |
|-------------|----------|
| Home sequence | typed boot log (`createTypedLog`, D-03 lines) → on `boot.done`, `CyLogo` DRAFT wordmark reveal → reveal `CREATE_DRAFT()` / join-by-code actions + Discord sign-in entry |
| Home `hot` shader | Home hero passes `hot` to the app-wide `CyShader` (Phase 9 D-02); other screens stay ambient. Hot placement beyond Home is discretionary |
| Drafting countdown urgency (D-04) | final 5s: shift clock to `--cy-red` + glow AND pulse (`cy-pulse`/`cy-blink`). Under `prefers-reduced-motion: reduce`: color shift ONLY, no pulse |
| Pick column | lime accent (`cy-pickslot-lime`, `cy-draft-col-lime`) |
| Ban column | red + struck-through (`cy-pickslot.is-ban` → opacity 0.4 + `line-through`; `cy-submit-ban` red); banned champ in grid gets red `cy-champ-x` overlay + dimmed |
| Drafting chat (D-02) | responsive: persistent right sidebar on desktop (`cy-chat-right`, `cy-draft-grid` gets `padding-right: 300px`), collapses to toggleable drawer/overlay on narrow widths (`cy-chat-drawer`, board full-width). Breakpoint value = Claude's discretion, follow cyber.css conventions |
| Champion grid | `repeat(7, 1fr)` default density (discretionary to adjust columns/density within token palette); states: selected (lime border+glow), banned/picked/disabled (opacity 0.3, not-allowed) |
| Review without auth | Review remains viewable without auth — behavior UNCHANGED, restyle only |
| Reduced-motion | all motion (wordmark reveal, blink cursor, pulse, shader) honors `prefers-reduced-motion` per Phase 8 D-10 / Phase 9; never gate visibility on motion |
| Blinking cursors | header brand + chat input `cy-chat-cursor` (`cy-blink` 1s step-end), suppressed under reduced motion (FX-05, already shipped) |

**Hard constraint:** No change to draft behavior. `$live/*` stores, snapshot shape, and realtime wiring are FROZEN. 130+ server unit tests and existing browser specs must stay green. Restyle in place (D-01).
