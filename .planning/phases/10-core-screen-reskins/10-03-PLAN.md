From src/routes/login/+page.server.js:
```
actions = {
  signin:   POST ?/signin   -> auth.api.signInSocial({ provider:'discord', callbackURL: ?redirect ?? '/' }) -> redirect to Discord
  register: POST ?/register -> same Discord OAuth flow with requestSignUp:true
  signout:  POST ?/signout
}
load: if already authed, redirects to ?redirect ?? '/'
```
The redirect target is read from `event.url.searchParams.get('redirect')`. The guest path must NOT hit a server action — it simply navigates to that same redirect target (the room) as an unauthenticated spectator (guest = spectator; load on the room route already handles unauthenticated viewers).
