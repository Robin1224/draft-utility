**Props (`$props()` with defaults so the spec can render it standalone):**
```svelte
<script>
  let { phase = 'lobby', code = null, children } = $props();

  const TRACKER = ['lobby', 'drafting', 'review'];                 // cyber.jsx:154
  const LABEL = { lobby: '01_LOBBY', drafting: '02_DRAFTING', review: '03_REVIEW' };
  const idx = $derived(TRACKER.indexOf(phase));                    // -1 for cancelled/unknown → no active step (D-07)

  async function copyCode() {
    if (!code) return;                                             // no-op when no room (D-09)
    try {
      await navigator.clipboard.writeText(code);
    } catch {
      /* clipboard unavailable / denied — silently ignore */
    }
  }
</script>
```

**Markup** — port CYChrome with D-06/D-07 overrides applied. Brand name `DRAFT_EM` must be its OWN span (brackets separate) so `getByText('DRAFT_EM')` resolves uniquely:
```svelte
<div class="cy-app">
  <div class="cy-shader"></div>                                   <!-- Phase 9 mount point — empty, NO canvas -->
  <div class="cy-scanlines"></div>
  <header class="cy-header">
    <div class="cy-brand">
      <span class="cy-brand-bracket">[</span>
      <span class="cy-brand-name">DRAFT_EM</span>
      <span class="cy-brand-bracket">]</span>
      <span class="cy-brand-cur" aria-hidden="true">▮</span>
    </div>
    <div class="cy-phases">
      {#each TRACKER as p, i (p)}
        <span class="cy-phase" class:is-active={i === idx} class:is-done={idx > -1 && i < idx}>
          {LABEL[p]}
        </span>
      {/each}
    </div>
    <div class="cy-meta">
      <span class="cy-meta-key">$ ROOM=</span>
      <span class="cy-meta-val">{code ?? '—'}</span>
      <button class="cy-meta-copy" type="button" onclick={copyCode} disabled={!code}>[copy]</button>
    </div>
  </header>
  <div class="cy-body">{@render children?.()}</div>
</div>
```

Notes:
- The `▮` cursor span is `aria-hidden` (decorative). Its blink + reduced-motion suppression live in `app.css` (Plan 01) — do not animate here.
- `disabled={!code}` makes `[copy]` a no-op/disabled on no-room screens (D-09); `{code ?? '—'}` shows the em dash.
- `class:is-active={i === idx}` is the ONLY active marker; when `idx === -1` (cancelled/unknown) no span matches → no `.is-active`, no crash (D-07).
- Render `{@render children?.()}` (optional chaining) so the spec, which renders CyShell without a `children` snippet, does not throw.
