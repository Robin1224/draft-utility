<objective>
Add the D-02 SSR half of the two-layer Guest Gate: the draft page load computes `gated` and returns a minimal-disclosure payload when it is true (ACC-03), while every non-gated path — signed in, public room, drafting, review, cancelled — returns `gated: false` so guests keep their spectator access (ACC-04).

Output: the `gated` computation in `src/routes/draft/[id]/+page.server.js` and the full gate matrix in `src/routes/draft/[id]/page.server.spec.js`.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser → SvelteKit SSR load | Untrusted route param (`params.id`) and a session-derived `locals.user`. This layer decides what the page RENDERS |
| SSR load → response body | Everything returned becomes `page.data`, readable in the browser devtools and in the serialized `__data.json` |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-12-09 | Information disclosure | gated load payload | mitigate | The gated early-return carries only `{ public_code, phase }` in `room`; `host_user_id` is omitted so an internal user id never ships on a 403 response. Asserted by `not.toHaveProperty('host_user_id')`. ASVS V8 |
| T-12-21 | Information disclosure | roster/action data on the gated path | mitigate | `loadDraftSnapshot` is not called when gated; the gated branch returns before the `review` branch is reached. Asserted by a not-called test |
| T-12-22 | Elevation of privilege | treating the SSR flag as access control | accept (documented) | `gated` is explicitly the UX layer and is trivially bypassable — a client can open the WebSocket directly and call `room/lobby` without ever fetching this page. The enforcement point is the `lobby` stream guard (Plan 07, T-12-01). Recorded here so no reviewer mistakes this plan for the boundary |
| T-12-23 | Tampering | gate predicate reading a falsy-but-absent flag | mitigate | Strict `row.is_public === false` rather than `!row.is_public`, so a row lacking the column (pre-migration state, or a hand-built fixture) does not gate every visitor. Every spec fixture carries an explicit `is_public` |
| T-12-13 | Information disclosure | room-code existence oracle (404 for a nonexistent code vs the gate for a real private one) | accept | Pre-existing response shape (`error(404)` already lives at `+page.server.js:12`); the 7-character code over a 54-character alphabet makes enumeration impractical. Do not expand scope to unify the responses |
| T-12-SC | Tampering | npm/pip/cargo installs | accept | This phase installs zero packages (`12-RESEARCH.md` § Package Legitimacy Audit: not applicable, verified against `package.json`). No install task exists in any Phase 12 plan |
