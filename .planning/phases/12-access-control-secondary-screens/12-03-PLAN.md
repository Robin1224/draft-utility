## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser → WebSocket (`/ws` → `src/live/room.js`) | The real authorization boundary. A scripted client can call `room/setRoomVisibility` directly without ever fetching a page, so `{#if isHost}` in Svelte is UX and this RPC head is enforcement |
| RPC handler → Postgres | Caller-supplied `publicCode` and `isPublic` reach Drizzle builders |
