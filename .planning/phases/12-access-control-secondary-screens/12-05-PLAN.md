## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| snapshot data → rendered DOM | `code`, `players`, `spectators` and `reason` arrive as props derived from a server-published snapshot and are interpolated into `<pre>` blocks |
| component → clipboard API | `$ COPY_LOG()` writes assembled log text to the system clipboard |
| component → navigation | The `$ NEW_DRAFT()` and `$ RETRY_LINK()` affordances leave the page |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
